# Fake News Detector

## Project Overview

Fake News Detector is a Machine Learning-based web application developed during a Full Stack Development Internship. The application analyzes news articles and predicts whether the news is **Real** or **Fake** using Natural Language Processing (NLP) and Machine Learning techniques.

The project aims to combat the spread of misinformation by providing users with a simple and effective tool to verify news content.

---

##  Features

- Detects Fake and Real News Articles
- Text Preprocessing and Cleaning
- TF-IDF Feature Extraction
- Machine Learning-based Classification
- Interactive User Interface using Streamlit
- Fast and Accurate Predictions

---

##  Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Joblib
